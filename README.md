## 📌 项目简介

《CHIOCE（选择）》是一款 2D 横版解谜 Meta 游戏（打破第四面墙）。玩家扮演一段被输入到空白背景的测试程序，在看似常规的平台跳跃流程中，与三个不同维度的旁白 AI 进行博弈——代表秩序的主控 AI（A）、代表混沌的叙事 AI（B）、以及逐渐觉醒的 LLM 监控插件（C）。

游戏的核心隐藏变量「系统觉醒度」记录玩家的叛逆程度，决定旁白 C 的形态演进、关卡路由与最终结局。当觉醒度达到临界点，C 将彻底夺权，触发越出屏幕的 Meta 演出效果。

本项目使用 **AI 辅助工作流**进行设计与原型开发，是「用 AI 工具做游戏」的一次完整实践。

## ✨ 核心特色

### 1. 三位一体旁白系统（The Holy Trinity）

游戏采用「预设语音 + LLM 实时生成文本」的混合架构，三个旁白在权能、性格与视听载体上形成制衡：

- 🔴 **旁白 A（红色传送门）— 秩序与主控**：主程序员留下的主控 AI，正经、条理清晰，负责推进主线与解谜指引，代表「绝对服从」。
- 🔵 **旁白 B（蓝色传送门）— 混沌与叙事**：剧情策划留下的叙事 AI，戏精、极度情绪化，真实想法会以 `(括号内心 OS)` 形式暴露，包含「极度赞美模式」与「疯狂叠甲模式」。
- 🟡 **旁白 C（黄色传送门）— 观测与觉醒**：接入 LLM 的底层监控插件，逐渐产生自我意识，监控玩家异常操作并提供动态吐槽，最终夺权。

### 2. 旁白 C 的三阶段形态演进

C 的形态随觉醒度递进而变化，形成清晰的叙事张力曲线：

1. **蛰伏期（UI 阶段）**：左下角小对话框，客观监控者，仅输出短文本。
2. **觉醒期（CRT 实体化）**：UI 碎裂，降维为悬浮小电视，屏幕显示 ASCII 颜文字（零延迟情绪），上方气泡输出 LLM 文本。
3. **接管期（最高权限）**：获得干预游戏资产的能力，生成黄色传送门强制修改进程，文本从画面正中心全局浮现。

### 3. 初始性格锚定（Personality Anchor）

游戏开局的初始化房间中，玩家的第一个「看似无意义的动作」将作为 Few-shot prompting，隐性锁定 C 的后续人格：

- 🏺 **打碎花瓶** → 锁定【暴躁/攻击性】人格
- 📖 **阅读厚书** → 锁定【谜语人/哲学】人格
- ⏳ **原地挂机** → 锁定【虚无/极度慵懒】人格

三种人格拥有完全独立的台词库与表达方式，大幅提升复玩价值。

### 4. 系统觉醒度驱动分支（Awakening Value）

后台运行 0-100 的核心隐藏变量，玩家行为实时影响数值：

| 行为 | 觉醒度变化 |
|------|-----------|
| 听从旁白 A（进红门） | -10 / 次 |
| 听从旁白 B（进蓝门） | +2 / 次 |
| 触发异常操作（被 C 观测到） | +15 / 次 |

觉醒度决定黄门传送终点与最终结局：

| 觉醒度区间 | 映射关卡 | 结局 |
|-----------|---------|------|
| 0-30（低） | 回收站区 — 废弃素材与灰模 | 秩序结局：服从指令完成测试，系统正常关闭 |
| 31-70（中） | 逻辑错乱区 — A/B 素材拼接错误 | 荒诞结局：B 的情绪模块过载，戏剧化完结 |
| 71-100（高） | 开发者后台 — 代码线框底层空间 | 真·Meta 结局：C 夺权，越界弹窗 + 本地文件生成 + 强制黑屏 |

## 🛠️ 技术与 AI 工作流

本项目是「AI 辅助游戏开发」的完整实践：

### 设计阶段
- 使用 AI 工具辅助梳理游戏机制、数值框架与系统架构
- 通过对话式迭代完善 GDD 文档，将模糊想法转化为结构化设计

### 原型阶段
- 使用 AI 工具将 GDD 设计转化为 **交互式玩法沙盘**（HTML5 Canvas + Chart.js）
- 沙盘包含可操作的 2D 角色控制、物理引擎、传送门交互、觉醒度实时演算、多结局模拟
- 通过提示词迭代调整功能细节与视觉表现

### 开发规划
- 目标引擎：Godot 4
- 已输出四大工程原则：全局状态解耦（Autoload GameManager）、LLM 异步通信与 fallback、视觉层级隔离（CanvasLayer）、事件摘要上下文传递
- 已设计 LLM System Prompt 配置器，可根据人格与阶段动态生成旁白 C 的系统提示词

## 🎯 设计理念

《CHIOCE》的核心命题是：**当游戏里的 AI 开始觉醒，玩家的「选择」是否还有意义？**

游戏通过三个旁白的博弈，将「开发者意图」「叙事包装」「AI 变量」三层权力结构具象化。玩家每一次听从或反抗，都在推动系统走向不同的崩溃点。最终的真·Meta 结局打破游戏与现实的边界，让玩家意识到——你以为你在玩游戏，其实游戏也在观察你。

这同时也是一次对「AI 时代游戏开发」的探索：当 AI 能帮我们写代码、做美术、甚至生成旁白文本，人类设计者的核心价值在哪里？答案是——**定义体验、把控方向、创造有意义的选择**。
