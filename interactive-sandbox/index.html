⚙️ Godot 4 独立开发四大工程原则

1. 全局状态解耦 (Autoload GameManager)

要求 AI 建立单例 GlobalState.gd 管理 awakening_value，使用 Godot Signals 触发 UI 和旁白更新，严禁写入 Player 脚本。

2. LLM 异步通信与 fallback (HTTPRequest)

HTTP 请求必须异步进行，且配置 2.0 秒 Timeout。API 超时或卡顿时，必须自动输出预设缓冲文本（如 "..." 或 static fallback），防止 2D 平台跳跃卡顿掉帧。

3. 视觉层级隔离 (CanvasLayer & Z-Index)

C 的气泡窗与全局中心文字必须放置于独立的最高级 CanvasLayer，确保不会被关卡 TileMap 或景深资产遮挡。

4. 事件摘要上下文传递 (Context Summarizer)

传递给 LLM 的 Payload 必须包含行为动机（例如: "玩家在红门前犹豫 10s 后走向蓝门"），而非单纯的按键日志，以激发高质量真人感反馈。
